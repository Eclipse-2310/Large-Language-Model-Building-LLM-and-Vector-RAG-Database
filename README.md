# Large Language Model (LLM) Development & Vector RAG Database

This repository documents my learning and hands-on experience in **Large Language Model (LLM) Development and Vector-Based Retrieval-Augmented Generation (RAG)** through an In-House Internship.

During this internship, I had the opportunity to work under the guidance of our mentor and explore how different types of LLMs function, how they process information, and what components are required to build an LLM-powered application.

Through practical implementation, I gained exposure to key concepts such as LLM architecture, embeddings, vector databases, semantic search, document processing, and Retrieval-Augmented Generation (RAG).

This experience helped me understand how LLMs can be integrated with external knowledge sources to develop intelligent applications that generate more relevant and context-aware responses.

**The repository includes my learning, experiments, implementations, and practical work related to LLM development and Vector RAG databases.**
